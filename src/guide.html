What should I do if my account was compromised?

Start on a device you trust. Secure your accounts before cleaning up messages.

  1. Secure your recovery email. Change its password, enable MFA, and remove unfamiliar sessions, recovery methods, and forwarding rules.
  2. Recover Discord. If the account email changed, check your previous inbox for Discord’s change notification and follow its recovery instructions. If you’re locked out, file a compromised account ticket. Once you have access, reset your password and review the email address and phone number on the account.
  3. Revoke access. In Discord User Settings, sign out unfamiliar sessions under Devices and remove unfamiliar or unused integrations under Authorized Apps. On mobile, open settings from your profile tab.
  4. Enable MFA. Set up a passkey, security key, or authenticator where available. Store backup codes somewhere secure and separate from the affected device.
  5. Review other accounts used on the device. Check active sessions and connected apps for your email, social networks, and messaging apps. Change reused passwords and revoke suspicious sessions.

Based on Discord’s compromised account guide. Submit a compromised account ticket.

How do I check the affected device?

  1. Remove software you don’t trust. Check unofficial Discord clients and plugins, including tools such as Nightcord or Epicord if installed. Uninstall suspicious software and remove browser extensions you don’t recognize. A tool’s presence alone does not identify the source of the compromise.
  2. Run a security scan. On Windows, open Windows Security → Virus & threat protection → Scan options. Run a full scan and use Microsoft Defender Offline if you suspect persistent malware. Install pending system and browser updates.

How do I report the scam?

  1. Report messages before deleting them. Right-click the message on desktop or press and hold it on mobile. Choose Report Message and select the category that fits. Keep message links or screenshots if you need them for your support ticket.
  2. Include unauthorized charges in your ticket. Tell Discord which transactions you didn’t make when you report the account compromise.
  3. Use official support channels. Ignore unsolicited DMs claiming to be Discord support. Keep passwords, login codes, and payment details out of DMs.

How do I set up a scan?

In the scanner’s Settings, save a Discord OAuth2 access token with the user ID left blank to fill it automatically. You can also enable Developer Mode in Discord, copy your user ID from your profile, and save it in the scanner.

Choose a local time range. For exact matches, use the original reference images. Enable suspicious message scanning to review rule-based flags, even without images.

How do I get an OAuth2 access token?

Personal scans and report review work without a token. Owner and moderation scans require a user access token with the identify and guilds scopes.

  1. Create an application in the Discord Developer Portal. Register your OAuth client’s redirect URL in the application’s OAuth2 settings.
  2. Start the authorization code flow from your OAuth client, request identify guilds, and sign in with the Discord account configured in the extension. Use a fresh state and have your client verify it on return.
  3. Use your OAuth client to exchange the returned code with grant_type=authorization_code and the registered redirect URL. Keep the application secret in the OAuth client.
  4. Copy the response’s access_token into the extension’s OAuth2 field and use the Save settings icon.

How do I review, delete, or restore matches?

Exact matches share an attachment hash with a reference image. Suspicious messages show the reason they were flagged and are available for manual review. In Results, select exact matches and open them with Review selected matches. An authorized server bot can remove the selected batch after you confirm it.

Use Saved scan to save, export, or import a checkpoint. An unfinished checkpoint can be resumed. An exported report opens for review.
