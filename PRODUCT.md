# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Discord users finding and reviewing suspicious messages after account compromise. Server owners and moderators are a secondary audience.

## Product Purpose

Discord Hack Cleaner helps a user narrow an incident by time and conversation, find suspicious or matching messages, and open those messages directly to review them.

## Capabilities and Constraints

The Chrome and Edge extension runs in Discord Web. It can check reference images by exact attachment hash, flag suspicious patterns, and resume incomplete scans. A configured server bot can remove selected exact matches where permissions are verified. Personal message removal uses Discord's own controls.

## Product Principles

- Keep dates, scope, reference images, and starting a scan easy to find in a narrow panel.
- Put optional shortcuts and administrative controls behind disclosure.
- Show enough evidence to review a match before removing it.
